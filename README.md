## English

### About

Billiards Mod adds a fully playable billiards (pool) table to Minecraft. Set up a table, grab a cue, and challenge your friends to a game, right inside your world.

### Features

- Placeable billiards table
- Realistic ball physics
- Cue mechanics for aiming and striking
- Multiplayer support
- Scoring and game rules based on classic pool

> Features listed above reflect the current development plan and may change before release.

### Requirements

| Requirement | Details |
|---|---|
| Minecraft Version | 1.21 |
| Mod Loader | Fabric |
| Dependencies | Fabric Loader, Fabric API |
| Java | Java 21 |

## Português

### Sobre

O Billiards Mod adiciona uma mesa de sinuca totalmente jogável ao Minecraft. Monte a mesa, pegue o taco e desafie seus amigos para uma partida, tudo dentro do seu mundo.

### Funcionalidades

- Mesa de sinuca posicionável
- Física realista das bolas
- Mecânica de taco para mirar e golpear
- Suporte a multiplayer
- Sistema de pontuação e regras baseadas na sinuca clássica

> As funcionalidades listadas acima refletem o plano de desenvolvimento atual e podem sofrer alterações até o lançamento.
